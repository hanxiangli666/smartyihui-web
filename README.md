# smartyihui-web

Vue/Vite business website for Guangzhou Yihui Intelligent Technology. The site presents company services, self-developed products, contact information, and a polished login/register interaction flow.

Live site: [www.smartyihui.com](https://www.smartyihui.com)

## What It Builds

- Responsive company homepage.
- About, services, products, contact, and 404 routes.
- Desktop and mobile navigation.
- Login/register modal.
- SMS verification UI.
- Dark/light theme toggle.
- Scroll progress and page transitions.
- Business-oriented hero, service cards, platform coverage, trust signals, and CTA sections.

## Tech Stack

- Vue 3
- Vite
- Vue Router
- Naive UI
- Axios
- Custom CSS

## Run Locally

```powershell

```

Build:

```powershell
npm run build
```
